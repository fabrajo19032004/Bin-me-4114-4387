# Configuration Accès Administrateur

Pour créer un nouveau compte administrateur, utilisez exclusivement le lien secret suivant :

**Lien de création (Secret) :** [http://localhost:8080/auth/register-admin-secret-gate](http://localhost:8080/auth/register-admin-secret-gate)

Note : Une fois le compte créé, la connexion s'effectue via la page de connexion standard.
